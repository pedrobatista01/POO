# Gerenciador Inteligente de Tarefas

## Sobre o projeto

O Gerenciador Inteligente de Tarefas é um sistema desenvolvido em Python
utilizando conceitos de Programação Orientada a Objetos (POO).

O sistema permite cadastrar usuários, criar projetos e gerenciar tarefas,
possibilitando o acompanhamento do progresso e a geração de relatórios
de produtividade.

## Objetivo

O objetivo do projeto é aplicar conceitos de Programação Orientada a
Objetos no desenvolvimento de um sistema de gerenciamento de tarefas.

## Funcionalidades

- Cadastro de usuários
- Listagem de usuários
- Remoção de usuários
- Criação de projetos
- Listagem de projetos
- Remoção de projetos
- Criação de tarefas
- Listagem de tarefas
- Remoção de tarefas
- Alteração de prioridade
- Alteração de status
- Cálculo do progresso dos projetos
- Relatório de produtividade

## Prioridades das tarefas

As tarefas possuem três níveis de prioridade:

- Baixa
- Média
- Alta

## Status das tarefas

As tarefas podem possuir três estados:

- Pendente
- Em andamento
- Concluída
